# 第 0 章 预备知识

## 0.1 深度学习在做什么：从函数拟合说起

深度学习模型，本质上是一个**非常复杂的函数**：

```
输出 = f(输入, 参数θ)
```

- 输入：一张影像（一堆数字组成的矩阵）
- 参数 θ：模型内部成千上万个"权重"数字，一开始是随机或预训练的
- 输出：预测结果（每个像素是不是滑坡）

**训练（training）** 的过程就是：不断调整 θ，让 `f(输入)` 的输出越来越接近"标准答案"（标签 mask）。

判断"接近不接近"，靠的是**损失函数（loss function）**；往哪个方向调参数，靠的是**梯度下降（gradient descent）** 和**反向传播（backpropagation）**。

> 直觉理解：就像调收音机旋钮让声音最清晰。模型输出和标签差得越远，loss 越大；训练就是"旋钮微调"的自动化过程。

---

## 0.2 几个必须背下来的基础术语

| 术语 | 含义 | 类比 |
|---|---|---|
| **张量 Tensor** | 多维数组，深度学习里的基本数据结构 | 一张影像 = (通道数, 高, 宽) 的 3 维张量 |
| **批次 batch** | 一次喂给模型的一小组样本 | 一次炒 16 个菜 |
| **batch size** | 一个 batch 里样本数量 | 每锅 16 个 |
| **epoch** | 完整看过一遍所有训练数据 | 把整本菜谱全部做了一遍 |
| **iteration** | 处理一个 batch 算一次 | 做一锅 |
| **学习率 lr** | 每次调参的步子大小 | 旋钮每次拧多少度 |
| **过拟合 overfitting** | 训练集很好、测试集很差（死记硬背） | 背答案但不会做题 |
| **欠拟合 underfitting** | 训练集都很差（没学会） | 根本没学会 |
| **泛化 generalization** | 在没见过的数据上表现好 | 会做新题 |

> 关系：`一个 epoch 的 iteration 数 = 训练样本数 ÷ batch size`

## 0.3 CNN（卷积神经网络）到底"看"到了什么

你会的 CNN，核心是三种操作叠起来：

### (1) 卷积层（Convolution）— 提取特征
- 用一个小"窗口"（**卷积核 kernel**，如 3×3）在图像上滑动，每次算一个加权和，得到新图像（叫**特征图 feature map**）。
- 不同卷积核学不同特征：有的学边缘、有的学纹理、有的学颜色。
- **通道 channel**：一个卷积核产生一张特征图；用 N 个卷积核就有 N 个通道。越深的层，通道越多，特征越抽象。
- **感受野 receptive field**：某个神经元"能看到"的原始图像范围。层越深，感受野越大，越能看到全局。

### (2) 池化层（Pooling）— 缩小尺寸、增强不变性
- 把特征图按区域取最大值（MaxPool）或平均值（AvgPool），尺寸变小。
- 作用：① 减小计算量；② 让模型对小的平移不敏感。

### (3) 激活函数（Activation）— 引入非线性
- 没有激活函数，多层卷积叠起来还是线性的，表达能力弱。
- **ReLU**：`max(0, x)`，最常用。
- **Sigmoid**：把输出压到 (0,1)，常用于二分类输出层。

> 滑坡识别里，CNN 的作用是：从"一堆像素颜色"里自动学到"滑坡长什么样"——比如滑坡往往有裸露土体、新鲜岩面、比周围植被更亮的纹理特征，这些不用人工设计，CNN 自己学。

## 0.4 迁移学习（Transfer Learning）是什么

从零训练一个 CNN 通常需要海量数据和算力。但 ImageNet 上有 100 万张自然图像，已经有人训练好了很会"看通用特征"的模型（叫 **backbone，骨干网络**）。

**迁移学习**：拿别人在 ImageNet 上训练好的 backbone 权重作为起点，再在你的滑坡数据上继续训练（**微调 fine-tune**）。

- 好处：数据少也能训好、收敛快、精度高。

> 📌 **本项目实际做法**：当前 U-Net 是**手写的、没有用预训练 backbone**（编码器就是普通卷积 `DoubleConv/Down`，从随机权重开始训练）。原因——项目以"理解原理 + 在 4GB 显存上跑通"为目标，手写 U-Net 更轻、更可控。迁移学习作为**可选拓展**留待以后（例如把编码器换成 ImageNet 预训练的 resnet34）。

# 第 1 章 模块① 问题定义：语义分割是什么

## 1.1 计算机视觉四大任务

| 任务 | 输出 | 粒度 | 例子 |
|---|---|---|---|
| **图像分类** | 一个类别标签 | 整张图 | "这张图含滑坡" |
| **目标检测** | 多个边界框 + 类别 | 物体级 | 框出每个滑坡的位置 |
| **语义分割** | 每个像素一个类别 | 像素级 | 每个像素标"滑坡/非滑坡" |
| **实例分割** | 每个像素 + 区分不同个体 | 像素级+个体 | 区分"第 1 个滑坡"和"第 2 个滑坡" |

## 1.2 为什么滑坡识别用"语义分割"

- 滑坡边界**不规则**，用矩形框（检测）会框进大量非滑坡区域；
- 灾害评估需要知道**确切的受灾范围、面积**，只有像素级 mask 才能算面积；
- 因此主流做法是**逐像素二分类**：输出一张和输入同尺寸的图，每个像素是 0（非滑坡）或 1（滑坡）。

## 1.3 二分类分割的输出层

模型最后一层输出每个像素一个分数，经过 **Sigmoid** 变成 (0,1) 的概率，再设一个**阈值**（默认 0.5）判断：

```
概率 > 0.5  → 预测为滑坡(1)
概率 ≤ 0.5  → 预测为非滑坡(0)
```

> 所以二分类分割模型的最终输出形状 = (1, 高, 宽)，每个值在 0~1 之间。

📌 **本项目实际写法（多类别交叉熵式）**：我们不输出单通道概率，而是让模型输出 **2 个通道**（背景 / 滑坡各一个 logit），训练用 `nn.CrossEntropyLoss`，推理时用 `torch.max` 取 2 个通道里值最大的那个作为预测类别（0 或 1）。这种写法**不需要 Sigmoid、不需要手动设 0.5 阈值**，是 PyTorch 分割任务最常见的标准写法。两种写法本质等价，只是实现不同——本项目选了后者。

# 第 2 章 模块② 数据层：遥感影像与预处理

## 2.1 遥感影像基础

**遥感（remote sensing）**：卫星/飞机/无人机搭载传感器，不接触地面就获取地表信息。

### 关键概念：分辨率（四种）

| 分辨率 | 含义 | Landslide4Sense 的情况 |
|---|---|---|
| **空间分辨率** | 一个像素代表地面多大 | ~10 m（一个像素 = 10m×10m） |
| **光谱分辨率** | 能分多细的波段 | 12 个波段 |
| **时间分辨率** | 多久重访一次 | Sentinel-2 约 5 天 |
| **辐射分辨率** | 亮度等级的精细度 | 一般 12 bit |

### 波段（band）与多光谱

人眼只能看红绿蓝 3 个波段。卫星传感器能"看"更多波段（近红外、短波红外等），叫**多光谱影像**。

- **真彩色（true color）**：红=红波段、绿=绿波段、蓝=蓝波段，看起来像人眼所见。
- **假彩色（false color）**：把近红外等波段映射到红绿蓝，植被会显得很红，常用于遥感目视解译。

**为什么多光谱对滑坡有用**：不同地物在不同波段的反射不同。裸土、植被、水体在近红外/短波红外上的差异，是识别滑坡的重要线索——CNN 能利用这些"人眼看不见"的信息。

### Sentinel-2 的 12 个波段（Landslide4Sense 数据来源）

| 波段 | 中心波长 | 用途 |
|---|---|---|
| B1 海岸气溶胶 | 443 nm | 大气、海岸 |
| B2 蓝 | 490 nm | 水体、大气校正 |
| B3 绿 | 560 nm | 植被 |
| B4 红 | 665 nm | 植被 |
| B5/B6/B7 红边 | 705/740/783 nm | 植被状态 |
| B8 近红外 | 842 nm | 植被、水体 |
| B8A 窄近红外 | 865 nm | 植被 |
| B9 水汽 | 945 nm | 大气 |
| B11/B12 短波红外 | 1610/2190 nm | 裸土、湿度、岩性 |

> 竞赛版 Landslide4Sense 还加了 **坡度（slope）和海拔（elevation）** 两个 DEM 派生通道，共 14 通道。地形因子对滑坡非常关键（滑坡多发生在陡坡）。

## 2.2 为什么遥感影像要"切片（tiling）"

原始遥感影像动辄几千×几千像素，直接送进 GPU 会爆显存。所以切成固定大小的小块 patch（Landslide4Sense 已经切好成 **128×128**）：

- 好处：① 符合 GPU 显存；② 增加样本数量；③ 便于组成 batch。
- 注意：L4S 已经切好，你**不需要自己切**；但如果你以后用毕节数据集，就要自己写切片脚本。

## 2.3 归一化（Normalization）

把像素值缩放到一个固定范围，让训练更稳定、收敛更快：

- **Min-Max 归一化**：`x' = x / 255`（对 8bit 图像），缩到 [0,1]。
- **Z-score 标准化**：`x' = (x - mean) / std`，用数据集的均值方差。

> 如果用 ImageNet 预训练 backbone，通常还要把影像按 ImageNet 的 mean/std 做标准化（SMP 库会自动处理）。

## 2.4 数据增强（Data Augmentation）

人为制造"新样本"，防止过拟合、提升泛化。常用几何/色彩增强：

| 增强 | 操作 | 作用 |
|---|---|---|
| 水平/垂直翻转 | 左右/上下镜像 | 让模型不依赖方向 |
| 随机旋转 | 转 90°/任意角 | 滑坡方向无关性 |
| 随机裁剪/缩放 | 改变尺度 | 适应不同大小滑坡 |
| 色彩抖动 | 亮度/对比度/饱和度扰动 | 适应不同光照 |
| **注意** | 图像和 mask 要**同步**做相同几何变换 | 否则标签错位 |

## 2.5 类别不平衡（Class Imbalance）

滑坡只占影像很小一部分，绝大多数像素是"非滑坡"。如果直接训练，模型会偷懒全部预测"非滑坡"，也能拿到很高的 Accuracy——但这毫无用处。

解决办法（会在方法层详细讲）：
1. 用 **Dice/Focal Loss** 等对不平衡不敏感的损失；
2. **加权损失**（给滑坡像素更大权重）；
3. 采样策略。

## 2.6 数据集划分

- **训练集 train**：用来调参数、学规律。
- **验证集 val**：训练过程中监控过拟合、调超参。
- **测试集 test**：最后一次性评估，**绝不在训练中偷看**。
- Landslide4Sense 已官方划分：train 3799 / val 245 / test 245，**直接沿用**。

# 第 3 章 模块③ 方法层：模型、损失与训练

## 3.1 编码器-解码器（Encoder-Decoder）结构

语义分割最主流的骨架，两段式：

```
输入影像 →【编码器 Encoder】→ 抽象特征(小尺寸、多通道) →【解码器 Decoder】→ 逐像素预测(恢复到原尺寸)
```

- **编码器**：不断下采样（池化/步长卷积），提取越来越抽象、感受野越来越大的特征。→ 常用预训练 backbone。
- **解码器**：不断上采样，把抽象特征逐步"放大"回原尺寸，并融合细节。
- 本质：**先压缩理解全局，再放大恢复细节**。

## 3.2 U-Net 详解（你的 baseline）

U-Net 是编码器-解码器的经典代表，名字来自其 U 形结构。

### 核心创新：跳跃连接（skip connection）

```
编码器第 i 层特征 ──(拼接)──> 解码器对应层
```

- 编码器下采样会丢失空间细节（边缘、小目标）。
- skip connection 把编码器每一层的**高分辨率特征**直接"抄"给解码器对应层**拼接（concatenate）**，恢复细节。
- 效果：既看到全局（深层大感受野），又保留细节（浅层高分辨率）。

### U-Net 的上下采样

- **下采样**：MaxPooling 或 stride=2 卷积，尺寸减半、通道加倍。
- **上采样**：两种方式：
  - **转置卷积（Transposed Conv / Deconv）**：可学习的"反向卷积"。
  - **双线性插值（Bilinear Interpolation）+ 卷积**：简单可靠，本项目手写 U-Net 就用 `bilinear=True` 这种方式（上采样后做双卷积）。

### 上采样 → 输出

最后一层用 1×1 卷积把通道数变成 1，再过 Sigmoid，得到 (1,H,W) 的概率图。

> 好消息：用 `segmentation-models-pytorch` 一行代码就能建 U-Net，你只需理解原理，不用手写细节。

## 3.3 Backbone（骨干网络）与 ResNet

backbone 就是编码器用的特征提取网络。U-Net 的编码器可以换成不同的 backbone。

### ResNet 的核心：残差连接（residual connection）

深层网络会有"梯度消失"问题，越深越难训练。ResNet 引入**残差块**：

```
输出 = 输入 + 卷积层(输入)     # 把输入"跳过"卷积直接加到输出
```

- 相当于让网络学"残差"（差异），而不是整个变换，好训练得多。
- 常见的：resnet18/34/50/101（数字=层数，越大越深越强但也越慢）。

### 轻量选择：EfficientNet

通过神经架构搜索，在同等参数下精度更高、更快，适合显存有限时用 efficientnet-b0。

> 本项目当前 U-Net 无预训练 backbone（手写编码器，从随机权重训练）；resnet34 / efficientnet-b0 这类预训练主干可作为后续拓展对比项。

## 3.4 DeepLabV3+ 与空洞卷积（ASPP）

### 空洞卷积（Dilated / Atrous Convolution）

普通卷积核是"连续"的；空洞卷积在核的像素之间插"洞"（空洞率 rate），**不增加参数却能扩大感受野**。

- 作用：在不下采样（不丢分辨率）的前提下，让网络看到更大范围。
- 对滑坡有用：滑坡是一个区域现象，需要大范围上下文判断。

### ASPP（Atrous Spatial Pyramid Pooling，空洞空间金字塔池化）

DeepLab 的招牌：**并行**多个不同空洞率的卷积（rate=6,12,18…），像"多个不同尺度的放大镜"同时看，再融合——多尺度感受野，对大小不一的滑坡都有好处。

DeepLabV3+ = 带 ASPP 的编码器 + 解码器，是目前分割效果很强的经典模型。

## 3.5 注意力机制 与 Attention U-Net

### 注意力（Attention）是什么

让模型"把力气花在重要的地方"：给不同位置/通道分配不同**权重**，重要的加大、无关的压小。

### Attention U-Net

在 U-Net 的 skip connection 上加了**注意力门（attention gate）**：让解码器在上采样时，自动聚焦在"滑坡所在区域"的特征上，抑制无关背景。

- 好处：对小目标、细节边界更敏感。
- 对滑坡有用：滑坡在整图里占比小，注意力能帮助模型不忽略它们。

## 3.6 Transformer 与 SegFormer

### 从 CNN 到 Transformer

CNN 靠卷积核（局部、固定窗口）看图像；Transformer 靠**自注意力（self-attention）**，让每个像素/块和全图其他位置"互相交流"，天然具有**全局感受野**。

### ViT（Vision Transformer）

把图像切成一个个 patch（如 16×16），当成"词"送进 Transformer。缺点是计算量大、需要大量数据。

### SegFormer（推荐对比模型）

- 一个轻量、分层的 Transformer 分割模型：多尺度特征 + 轻量 MLP 解码器。
- 特点：结构简单、训练高效、精度高、不用位置编码、对分辨率鲁棒。
- 在滑坡识别中，Transformer 的全局上下文有助于理解大范围地貌。

> 规划的实验主线：**U-Net（CNN 经典，已完成）→ DeepLabV3+（多尺度空洞卷积）→ SegFormer（Transformer）**，正好构成"从 CNN 到 Transformer 的对比"这条漂亮的报告主线（后两者待实现）。

## 3.7 损失函数（Loss Function）详解

损失衡量"预测"和"标签"差多少，训练就是最小化它。

### (1) 二值交叉熵 BCE（Binary Cross Entropy）

对每个像素独立计算：

```
BCE = -( y·log(p) + (1-y)·log(1-p) )
```

- y 是真实标签（0/1），p 是预测概率。
- 预测越错，loss 越大。
- 缺点：对**类别不平衡敏感**（非滑坡像素太多，会淹没滑坡像素的贡献）。

### (2) Dice Loss

源自 Dice 系数（衡量两个集合重叠程度，见第 4 章）。Dice Loss = 1 − Dice：

```
Dice = 2·|A∩B| / (|A|+|B|)
```

- 直接优化重叠度，对**类别不平衡不敏感**，非常适合滑坡这种小目标分割。
- 缺点：训练可能不稳定（梯度波动大）。

### (3) Focal Loss

对 BCE 的改进，给"难分的、少数类"像素更大权重：

```
FL = -α·(1-p)^γ · log(p)      # γ 越大，越聚焦难样本
```

- α 平衡正负类，γ 控制难样本权重。
- 目的：让模型别总被"容易的多数类"带偏，专注学习难分/少数类。

### (4) 组合损失（推荐实践）

实践中常用 **BCE + Dice** 的组合，兼顾稳定性和重叠度优化。滑坡项目常见选择：`BCE + Dice` 或 `Focal + Dice`。

> 📌 **本项目实际用的损失**：`scripts/losses.py` 当前只实现了 `CrossEntropyLoss`（配合 2 通道输出），还没做 Dice / Focal / 组合。CrossEntropy 对类别不平衡不如 Dice/Focal 鲁棒，但实现最简单、训练稳定，适合先跑通 baseline；Dice/Focal 留作后续消融实验。

## 3.8 优化器（Optimizer）

优化器决定"怎么用梯度更新参数"。

| 优化器 | 特点 |
|---|---|
| SGD | 经典，需调学习率，收敛慢但泛化有时更好 |
| Adam | 自适应学习率，收敛快、省心，最常用 |
| **AdamW** | Adam + 权重衰减解耦，**当前推荐默认** |

> 本项目当前 `train.py` 用 **Adam**（lr=1e-3，weight_decay=5e-4），不是 AdamW。AdamW 可作为后续对比项；学习率 1e-3 起步。

## 3.9 学习率调度 与 早停

### 学习率调度（LR Scheduler）

训练中动态调整学习率，通常"前期大、后期小"：

- **Cosine**：按余弦曲线衰减，SMP/现代训练常用。
- **ReduceLROnPlateau**：验证指标不再提升时自动降 lr。
- **Step**：每隔固定 epoch 降为原来的 1/10。

### 早停（Early Stopping）

验证集 loss/IoU 连续 N 个 epoch 不提升就停止训练，防止过拟合，并保存最优 checkpoint。

# 第 4 章 模块④ 实验层：评估指标与实验设计

## 4.1 混淆矩阵与 TP/FP/TN/FN

对每个像素，把"预测"和"真实"交叉统计：

| | 预测=滑坡 | 预测=非滑坡 |
|---|---|---|
| **真实=滑坡** | **TP**（真阳性，对了） | FN（假阴性，漏检） |
| **真实=非滑坡** | FP（假阳性，误检） | **TN**（真阴性，对了） |

记忆：第一个字母 T/F = 预测对不对，第二个字母 P/N = 预测成了什么。

- **TP**：真滑坡，预测也是滑坡 ✅
- **FN**：真滑坡，预测成非滑坡 → **漏检**（最危险）
- **FP**：不是滑坡，预测成滑坡 → **误检/虚警**
- **TN**：不是滑坡，预测非滑坡 ✅

## 4.2 为什么不能用 Accuracy（准确率）

```
Accuracy = (TP+TN) / 全部像素
```

滑坡像素占比可能只有 1%~5%。模型**全部预测"非滑坡"**，Accuracy 也能到 95%+，但一个滑坡都没找到——**高 Accuracy 是假象**。

→ 滑坡识别**主指标必须用 IoU 和 F1**，它们对类别不平衡鲁棒。

## 4.3 核心指标

### Precision（查准率）= TP / (TP + FP)
"预测为滑坡的像素里，有多少真的是滑坡"。越高 → 误报越少。

### Recall（召回率）= TP / (TP + FN)
"真实滑坡像素里，有多少被找出来了"。越高 → 漏检越少。

> 两者是**跷跷板**：调阈值让 Precision 高，Recall 往往就低。灾害场景通常希望**漏检少（Recall 高）**，但也别误报太多。

### F1 Score = 2·P·R / (P + R)
Precision 和 Recall 的调和平均，二者均衡时的综合指标。对不平衡任务比 Accuracy 可靠。

### IoU（Intersection over Union，交并比）

```
IoU = |预测∩真实| / |预测∪真实| = TP / (TP + FP + FN)
```

- 直观理解：预测的滑坡区域和真实滑坡区域，**重叠部分占合并部分的比重**。
- 完全重合 = 1，完全不重合 = 0。
- 通常报告 **滑坡类 IoU**（也叫正类 IoU），这是分割的核心指标。

### mIoU（mean IoU）

所有类别 IoU 的平均。二分类时就是"滑坡 IoU"和"非滑坡 IoU"的平均。

> 数学关系：**Dice 系数 = F1 = 2·IoU/(1+IoU)**，三者本质同源，报告时写清楚用哪个即可。

## 4.4 实验设计三原则

1. **控制变量**：对比实验只改变一个因素（如只换模型，其余数据/损失/超参完全一致）。
2. **可复现**：固定随机种子（seed），记录超参。
3. **多次取均值（可选）**：重要实验跑 2~3 次取平均，报告更严谨。

### 对比实验 vs 消融实验

- **对比实验**：不同模型（U-Net / DeepLabV3+ / SegFormer）在相同设置下比 IoU/F1。
- **消融实验（ablation）**：固定模型，逐个去掉/改变某组件，看它的贡献：
  - 换损失（BCE vs Dice vs Focal vs 组合）
  - 换 backbone（resnet34 vs efficientnet-b0）
  - 有无数据增强
  - 用 RGB 3 波段 vs 全 12 波段
  - 有无加坡度/高程通道

消融实验是"证明你的设计有效"的关键，报告里最能体现工作量。

# 第 5 章 模块⑤ 结果层：可视化与误差分析

## 5.1 可视化（报告必备图）

| 图 | 内容 | 用途 |
|---|---|---|
| **预测叠加图** | 原图 + 预测 mask 半透明叠加 | 直观展示效果 |
| **三栏对比图** | 原图 / 真实标签 / 预测 | 定性看对不对 |
| **损失曲线** | 训练/验证 loss 随 epoch 变化 | 看收敛、过拟合 |
| **IoU/F1 曲线** | 验证指标随 epoch 变化 | 看精度趋势 |
| **混淆矩阵热力图** | 2×2 的 TP/FP/FN/TN | 看误检漏检分布 |

> 报告里"一张好图胜过千言"，至少要有一张典型样例对比图（好的案例 + 差的案例）。

## 5.2 误差分析（Error Analysis）

把预测错误的像素挑出来，分析原因，这是研究报告"有深度"的标志：

### 漏检（FN，滑坡没识别出来）常见原因
- 小滑坡、薄层滑坡，特征不明显；
- 低对比度、阴影、云遮挡；
- 与周围裸土/道路颜色接近。

### 误检（FP，把非滑坡当成滑坡）常见原因
- 道路、采石场、裸露岩体、河滩——和滑坡一样是"裸土"；
- 云影、建筑物阴影；
- 季节性植被变化（如收割后的农田）。

### 分析方法
1. 统计错误像素的空间分布；
2. 挑典型错误案例贴图；
3. 归纳错误类型，提出针对性改进（如加 DEM 通道区分道路/岩体、用多时相）。

# 第 6 章 模块⑥ 讨论与结论

## 6.1 讨论要回答的问题

- 哪个模型最好？好多少？（引实验表数据）
- **为什么**？结合模型特性解释（如 Transformer 全局感受野有助于大区域滑坡、U-Net 细节恢复好但感受野有限等）。
- 精度和效率怎么权衡？（给参数量/推理速度对比，若有条件）
- 结果和已有论文（如 L4S 竞赛基准）相比如何？

## 6.2 研究局限（诚实写，反而加分）

- 只用单一数据源（Sentinel-2），中分辨率，小滑坡识别受限；
- 仅单时相影像，无法利用"滑坡前后变化"这一强信号；
- 未充分融合地形/地质/降雨等先验；
- 样本量和研究区有限，跨区域泛化未充分验证。

## 6.3 未来方向（体现前瞻性）

- 多时相变化检测（灾前/灾后对比）；
- 多模态融合（光学 + DEM + 坡度 + 地质 + 降雨）；
- Transformer 轻量化与边缘部署；
- 弱监督/自监督（减少标注依赖）。

## 6.4 结论怎么写

用 3~5 句话收束：
1. 做了什么（任务、数据、模型）；
2. 主要发现（哪个模型最优、IoU/F1 多少）；
3. 消融揭示的关键结论（如"加入坡度通道显著提升"）；
4. 意义与展望。
